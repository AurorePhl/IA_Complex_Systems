Pour le moment, les robots bougent aléatoirement toutes les 0.5s (haut, bas, gauche, droite). Dès qu'ils ont trouvé un survivant (triangle), ils le récupèrent, envoient l'information à la base (compte des survivants). Ils se redirigent automatiquement vers le QG (comme pour le poser après avoir prévenu le QG) avec une fonction de chemin le plus proche. Sur le chemin du retour, ils ne peuvent plus prendre de survivants.
